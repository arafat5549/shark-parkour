# 🦈 海底鲨鱼跑酷（Deep Sea Shark Parkour）

选择不同鲨鱼类型后，**专属能力会自动分配**。在深海躲避珊瑚、水雷与水母，收集珍珠，越游越远。

## 🌐 在线游玩

GitHub Pages（PWA，可安装到手机桌面）：

```text
https://arafat5549.github.io/shark-parkour/
```

## 敌人与背景鱼区分

- 会碰撞的敌人（礁石/水雷/水母）都带有 **红色危险描边 + 脉动红圈 + “!” 警示标**
- 背景热带鱼是半透明装饰，无红色警示标，不会造成伤害

## 操作

- 📱 手机：**按住屏幕 = 上浮，松开 = 下潜**；点右下角圆形按钮释放能力
- ⌨️ 电脑：`空格 / W / ↑` 上浮，`S / ↓` 下潜，`X / Shift / J` 释放能力
- `Esc / P` 暂停

## 热带鱼装饰

海底会随机出现 6 种热带鱼：小丑鱼、蓝倒吊、黄高鳍刺尾鱼、皇帝神仙鱼、蝴蝶鱼、七彩麒麟鱼，并区分远景/近景鱼群。

鱼群数量与游动速度可在 `src/game/config.js` 中调整：

```js
tropicalFish: {
  enabled: true,
  density: 1.6, // 游戏内参数面板可实时调节：0~2.5
  minFish: 10,
  maxFish: 32,
  areaDivisor: 30000,
  speedMin: 0.05,
  speedMax: 0.13,
}
```

> 游戏菜单左上角和游戏内右上角都有 **⚙️ 参数** 按钮，可实时调整并自动保存在手机浏览器中，无需修改代码。

## 下沉速度调参

当前默认已把下沉调慢。所有升降手感参数集中在 `src/game/config.js`：

```js
gravity: 1.45,       // 下沉重力系数：越小下沉越慢
lift: 4.8,           // 按住上浮力度：越大上升越快
dive: 4.6,           // 主动下潜力度
drag: 2.2,           // 水阻：越大越跟手
maxSinkSpeed: 0.62,  // 最大下沉速度（屏幕高度倍率/秒）
maxRiseSpeed: 1.02,  // 最大上浮速度
```

例如想让下沉更慢，把 `gravity` 改为 `1.15`、`maxSinkSpeed` 改为 `0.5` 即可。

## 开发

```bash
npm install
npm run dev       # Vite 开发服务器，端口 5174
npm run build     # 构建到 dist/
npm start         # Node + Express 托管 dist，端口 3002
```

## PWA / 离线

- 生产构建自动注册 Service Worker（`import.meta.env.PROD`）
- 提供 192 / 512 / maskable / apple-touch 图标
- 构建后可通过 `npm start` 或任意静态托管离线打开

## Git 仓库与 CI

- GitHub 仓库：https://github.com/arafat5549/shark-parkour
- 仓库当前为 **Public**，推送 `main` 后会自动构建并部署到 GitHub Pages
- 若切换回 Private：CI 会自动跳过 Pages 公开部署，只保留构建产物；支持私有 Pages 的付费账号可在仓库 Variables 设置 `ENABLE_PRIVATE_PAGES=1`

本地推送：

```bash
cd shark-parkour
git add .
git commit -m "更新内容"

```
